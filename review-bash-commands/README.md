**Learning objective:** In this exercise, you'll refresh your knowledge of essential Bash commands for navigating the file system and manipulating files and directories.

Before we dive into scripting, let's make sure we have a solid foundation in basic Bash commands. These commands will be the building blocks of our scripts, allowing us to perform various tasks efficiently.

## Commands to Review

- `ls`: List files and directories
- `cd`: Change directory
- `pwd`: Print working directory
- `mkdir`: Create a new directory
- `touch`: Create a new file
- `cp`: Copy files and directories
- `mv`: Move or rename files and directories
- `rm`: Remove files and directories

## Practice

1. Navigate to your home directory using the `cd` command.

2. Create a new directory called `bash_scripts` using the `mkdir` command.

3. Change into the `bash_scripts` directory using the `cd` command.

4. Create a new file called `first_script.sh` using the `touch` command.

5. List the contents of the `bash_scripts` directory using the `ls` command.
