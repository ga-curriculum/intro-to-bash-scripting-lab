## Lab requirements

The following requirements describe the functionality that should be present in the lab and the points awarded out of 100 for each piece of functionality.

| Criteria                                                                                                                                                                                                      | Points |
|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|--------|
| The <code class="filepath">first-script.sh</code> script exists.                                                                                                                                              | 2      |
| The <code class="filepath">first-script.sh</code> script is executable when cloned from GitHub.                                                                                                               | 3      |
| The <code class="filepath">first-script.sh</code> script contains the correct shebang line.                                                                                                                   | 3      |
| The <code class="filepath">first-script.sh</code> script contains a variable called `name` that is assigned the value of the first command-line argument.                                                     | 3      |
| When executed, the <code class="filepath">first-script.sh</code> script prints the text `This is my Bash script!` to the screen.                                                                              | 3      |
| When executed, the <code class="filepath">first-script.sh</code> script greets the user with the name provided as a command-line argument.                                                                    | 3      |
| When executed, the <code class="filepath">first-script.sh</code> script displays the current date.                                                                                                            | 3      |
| The <code class="filepath">build-project.sh</code> script exists.                                                                                                                                             | 8      |
| The <code class="filepath">build-project.sh</code> script is executable when cloned from GitHub.                                                                                                              | 9      |
| The <code class="filepath">build-project.sh</code> script contains the correct shebang line.                                                                                                                  | 9      |
| When executed, the <code class="filepath">build-project.sh</code> script creates a new directory that matches the name of the project provided as a command-line argument.                                    | 9      |
| When executed, the <code class="filepath">build-project.sh</code> script creates a <code class="filepath">README.md</code> file in the created directory.                                                     | 9      |
| When executed, the <code class="filepath">build-project.sh</code> script creates a new script file matching the project name that has a <code class="filepath">.sh</code> extension in the created directory. | 9      |
| When executed, the <code class="filepath">build-project.sh</code> script initializes a new Git repository in the created directory.                                                                           | 9      |
| When executed, the <code class="filepath">build-project.sh</code> script makes the new script file executable for the local user.                                                                             | 9      |
| When executed, the <code class="filepath">build-project.sh</code> script makes the new script file executable for anyone who clones the script from GitHub.                                                   | 9      |
| **Total possible points**                                                                                                                                                                                     | 100    |
